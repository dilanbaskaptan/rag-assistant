# Python Temelleri

Python, 1991 yılında Guido van Rossum tarafından geliştirilen, okunabilirliği ön planda tutan yorumlanan (interpreted) bir programlama dilidir. Java veya C++'ın aksine değişken tanımlarken tür belirtmek zorunlu değildir; Python türleri çalışma zamanında (runtime) otomatik olarak belirler. Bu özelliğe "dinamik tipleme" denir.

Python'da kod blokları süslü parantez `{}` yerine girinti (indentation) ile belirlenir. Bu, dilin okunabilirliğini artırır ama girinti hatalarının derleme hatası yerine çalışma zamanı hatası olarak ortaya çıkmasına da yol açabilir. Bir fonksiyon tanımlamak için `def` anahtar kelimesi kullanılır, örneğin `def topla(a, b): return a + b`.

Python'ın en güçlü yanlarından biri geniş standart kütüphanesi ve `pip` paket yöneticisi ile erişilebilen üçüncü parti kütüphaneleridir. `sqlite3`, `json` gibi modüller ek kurulum gerektirmeden dilin içinde hazır gelir; `flask`, `numpy`, `openai` gibi kütüphaneler ise `pip install` ile eklenir.
